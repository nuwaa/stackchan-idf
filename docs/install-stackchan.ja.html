  2. USBデータケーブルでCoreS3を接続し、シリアルモニターを閉じます。
  3. 下の2項目を確認し、表示されるINSTALLボタンを押します。

ATOM S3R用ではありません。M5Stack CoreS3 + ｽﾀｯｸﾁｬﾝベース専用です。他の端末には書き込まないでください。

書き込み後

自動で再起動します。以前の設定は保持されます。初めて使う場合は本体の設定画面で「音響リアクション」モードを選び、保存後に再起動してください。
