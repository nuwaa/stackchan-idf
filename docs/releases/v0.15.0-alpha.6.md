# v0.15.0-alpha.6

## 主な変更点

- CoreS3 で ggwave Audible Normal の音響メッセージを受信し、呼びかけに応じて音声・表情・首振りで反応する完全オフラインの「音響リアクション」モードを追加しました。
- 半角カタカナ、繁体字・簡体字中国語、カラー絵文字を画面表示できるようにしました。
- CoreS3 内蔵スピーカーの増幅率を従来の `4` から `6` に上げ、音響リアクション時の音声を聞き取りやすくしました。

## 注意事項

- 音響リアクションモードでは、マイクを専用受信処理が使用するため Wi-Fi と BLE は停止します。
- 大音量で音割れや不安定な動作が起きる場合は、設定画面のスピーカー音量を下げてください。
