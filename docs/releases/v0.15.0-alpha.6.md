# v0.15.0-alpha.6

## 主な変更点

- CoreS3 で ggwave Audible Normal の音響メッセージを受信し、呼びかけに応じて音声・表情・首振りで反応する完全オフラインの「音響リアクション」モードを追加しました。
- 半角カタカナ、繁体字・簡体字中国語、カラー絵文字を画面表示できるようにしました。
- CoreS3 内蔵スピーカーの増幅率を従来の `4` から `6` に上げ、音響リアクション時の音声を聞き取りやすくしました。

## 注意事項

- 音響リアクションモードでは、マイクを専用受信処理が使用するため Wi-Fi と BLE は停止します。
- 大音量で音割れや不安定な動作が起きる場合は、設定画面のスピーカー音量を下げてください。

## 実機確認と配布

2026年10月26日にM5ｽﾀｯｸﾁｬﾝ（CoreS3）で、Web版ggwave Audible Normalからの受信、
音声応答、表情、うなずき、左右の首振りを確認しました。半角カタカナ、簡体字、繁体字、
カラー絵文字の受信表示も確認済みです。

リリースは[GitHub Releases](https://github.com/nuwaa/stackchan-idf/releases/tag/v0.15.0-alpha.6)
に保存し、[Can You Hear the Data?](https://github.com/nuwaa/Can-You-Hear-the-Data)
側にM5ｽﾀｯｸﾁｬﾝ専用Webインストーラーを用意しました。

- 自動言語選択: <https://nuwaa.github.io/Can-You-Hear-the-Data/install-stackchan.html>
- 日本語: <https://nuwaa.github.io/Can-You-Hear-the-Data/install-stackchan.ja.html>
- English: <https://nuwaa.github.io/Can-You-Hear-the-Data/install-stackchan.en.html>
- 简体中文: <https://nuwaa.github.io/Can-You-Hear-the-Data/install-stackchan.zh-CN.html>

WebインストーラーはCoreS3用の6個のイメージを所定アドレスへ個別に書き込み、全消去を
要求しないため、既存のNVS設定を保持します。ATOM S3R用ページと配布ファームウェアは
別系統のまま維持しています。
