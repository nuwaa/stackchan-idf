- **母音に合わせて口の形が変わるマイク口パク (お試し機能)**: マイク口パク モードで、声の共鳴 (フォルマント) から「あいうえお」を推定し、母音ごとに口の開きと横幅を変えます (あ = 大きく開く、い = 横に平たく、う = 小さくすぼめる、え = 半開き、お = 丸く)。子音や息の部分は声の大きさで小さく開閉。設定ページ (BLE / Wi-Fi) の「母音に合わせて口の形を変える」で OFF にすると従来の大きさだけの口パクに戻ります (再起動で反映)。CoreS3 の実機マイクで録った声を混ぜて学習していますが、声の高さによっては あ・お を取り違えることがあります
- **聞き取った母音を吹き出しに表示 (デバッグ)**: Wi-Fi 設定ページの「聞き取った母音を吹き出しに表示する (デバッグ)」を ON にすると、認識した母音が吹き出しに出ます (即時反映)。上の機能の確認用です
- **XiaoZhi 対応の修正**: 応答待ちがタイムアウトしたとき、サーバーに中断を伝えて聞き取りに戻るようにしました (無言のまま固まるのを防ぐ)。接続時に自前サーバーの既定の笑顔表情を止めるようにしました
- 開発用ツール: 会話スタック (XiaoZhi サーバー / LLM / TTS) の状態とログをブラウザで見るモニターを追加

このアルファで確認したいこと: マイク口パクで あいうえお に合わせて口の形が変わるか (吹き出しデバッグで認識母音を見ながら)、自分以外の声・高い声でどのくらい合うか、母音モードを OFF にしたときに従来どおり動くか。AtomS3R での動作。
