# ggwave 音響リアクション

CoreS3 の内蔵マイクで ggwave の文字列を受信し、表情・首振り・吹き出し・ローカル音声で反応する完全オフライン動作モードです。ブラウザー側は ggwave 0.4 の **Audible Normal (protocol 0)**、可変長 UTF-8、最大 140 byte を使用してください。

## 動作モードの選択

設定ページまたは本体 UI で動作モードを `音響リアクション (acrx)` に変更し、再起動します。設定変更時には BLE または Wi-Fi を利用できますが、このモードの起動後は Wi-Fi、Bluetooth、クラウド会話、RTP、カメラを起動しません。

受信中は内蔵マイクを 48 kHz / mono / signed 16-bitで読み、隣接サンプルを平均してggwave用の24 kHz / 512 sampleへ変換します。Web版との互換用にAudible Normal / Fast / Fastest（ID 0～2）を受け付け、通常はAudible Normalを使用します。デコード後はマイクとdecoderを停止してから発話し、再生終了後に受信を再開します。同一メッセージの5秒以内の再受信は無視します。この半二重設計のため、スタックチャンが話している間に送られた音は受信できません。

## 既定リアクション

マッチング時は ASCII の大小文字、全角英数字、空白と句読点を正規化します。複数の語を含む場合は表の上ほど優先します。受信文字列は、リアクションに一致しない場合も吹き出しへ表示されます。

| 受信語の例 | 表情・動作 | 発話 |
|---|---|---|
| `壊れた`、`こわれた`、`故障` | Sad、下を向く | こわれてないよ |
| `かわいい`、`可愛い`、`cute` | Happy、うなずく | えへへ、ありがと |
| `元気`、`げんき`、`調子` | Happy、うなずく | げんきだよ！ |
| `你好`、`您好` | Happy | にーはお！ |
| `hello`、`hi` | Happy | はーい！ |
| `こんにちは`、`こんちは` | Happy | よんだ？ |

## ビルドと書き込み

ESP-IDF 5.5 の環境を有効にしてから実行します。

```sh
tools/apply-m5-patches.sh
make set-target BOARD=cores3
make build BOARD=cores3
make flash BOARD=cores3 PORT=COM8
make monitor BOARD=cores3 PORT=COM8
```

COM ポート名は使用環境に合わせて変更してください。Web Flasher を使う場合は、この変更を含む CoreS3 リリースイメージが必要です。

## 実機確認チェックリスト

1. `音響リアクション (acrx)` を選択して再起動し、ログに `AcousticReaction` と `listening: ggwave` が出ることを確認する。
2. PC/スマートフォンの ggwave 0.4 送信ページで Audible Normal を選び、音量を低めから調整する。
3. `ｽﾀｯｸﾁｬﾝ、こんにちは` を送信し、吹き出し表示、Happy 表情、発話、首の動作を確認する。
4. `你好，Stack-chan`、`Hello Stack-chan`、`スタックチャン、元気？`、`スタックチャン、かわいい`、`ｽﾀｯｸﾁｬﾝ、故障したの？` でも表の反応を確認する。
5. 無関係な文を送り、吹き出しには表示されるが発話しないことを確認する。
6. 同じ文を 5 秒以内に二度送り、二度目が無視されることを確認する。5 秒後には再び反応することも確認する。
7. 機内モードなどネットワークのない状態で繰り返し受信できることを確認する。
8. 発話終了後に次の音を受信できること、およびスピーカー音を自分で誤受信しないことを確認する。

認識しにくい場合は、送信機を 20–80 cm 程度に置き、送信音量、周囲の騒音、CoreS3 の向きを調整してください。サーボの方向と可動範囲は機体ごとのキャリブレーションに依存します。

## 実装と依存関係

受信器と判定ロジックは `components/acoustic_reaction`、M5Unified のマイク・スピーカー所有権を含む実行タスクは `main/acoustic_reaction_task.cpp` にあります。ggwave は upstream の Arduino 向けソースを `third_party/ggwave` に固定して同梱しています。由来とライセンスは同ディレクトリの `UPSTREAM.txt` と `LICENSE` を参照してください。
